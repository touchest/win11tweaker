Настройка, очистка и обслуживание Windows 10 и 11 без блуждания по сотне галочек.
Вы отвечаете на простые вопросы («Пользуетесь Xbox?», «Есть принтер?»), а остальное
программа делает сама: гасит ненужные службы, убирает мусор, сносит встроенный хлам.

Каждое изменение ложится в журнал рядом со старым значением, поэтому откат в один клик.
Код открыт целиком, так что можно проверить самому: ничего лишнего внутри нет.

## Что делает

- **Мастер настройки.** Один опросник закрывает службы, твики и встроенные приложения.
  Ответы запоминает, второй раз спрашивает только про новое. Зависимости служб считаются
  заранее, поэтому нужное не отключится случайно.
- **Твики системы.** Контекстное меню, Проводник, панель задач, приватность и телеметрия,
  службы Windows, Defender, UAC, глубокие ключи реестра.
- **Очистка диска.** Временные файлы, кэш обновлений, логи, дампы, хранилище компонентов
  WinSxS, папка Windows.old. Сначала показывает объём, потом чистит.
- **Снос встроенного.** Приложения из коробки, OneDrive, Edge WebView2 вместе со службами
  обновления, с блокировкой самовосстановления, чтобы ничего не вернулось после апдейта.
- **Фоновое обслуживание.** Автоочистка, разгрузка памяти при нехватке, управление
  охлаждением видеокарты по температуре через NVML, проверка автозапуска.
- **Откат.** Журнал изменений со старыми значениями и точка восстановления Windows перед
  пакетом твиков.

## Стек

.NET 10 и WPF. Два проекта:

| Проект | Роль |
| --- | --- |
| `Win11Tweaker.Core` | Про интерфейс ничего не знает. Хранит модель твика. |
| `Win11Tweaker.App` | Оболочка на WPF. |

Разнесены так, чтобы применение потом переехало в отдельный процесс с правами, а окно
осталось без админа.

Твик это данные, а не код. `TweakDefinition` описывает, что писать, на каких сборках,
с чем конфликтует и насколько рискованно. Движок один на все. Состояние всегда читается
с машины, а не угадывается, и важнее всего `Drifted`: ключ есть, но выставили его не мы.
На заезженной винде это сплошь и рядом.

## Сборка

Нужен .NET SDK 10.

```
dotnet build Win11Tweaker.slnx
dotnet run --project src/Win11Tweaker.App
```

Один самодостаточный exe, работает без установленного .NET:

```
dotnet publish src/Win11Tweaker.App -c Release -r win-x64 --self-contained -p:PublishSingleFile=true
```

## Заметки

- Часть твиков требует прав администратора, а изменения служб встают в силу только после
  перезагрузки.
- Управление охлаждением видеокарты работает с картами NVIDIA, которые отдают NVML. На
  остальных этот раздел просто выключен.
- Собрано и проверено на Windows 10 и 11, 64-бит. Старые сборки не цель.
- Снос OneDrive и Edge WebView2 сделан осознанно и из программы откатывается тяжело,
  так что убедитесь, что они вам правда не нужны.
